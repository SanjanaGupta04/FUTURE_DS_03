# 📊 Marketing Funnel Analysis Dashboard

## 📌 Project Overview

This project was completed as **Task 3 during my Data Analytics Internship at Future Interns**.

The objective of this project is to analyze marketing funnel performance and understand customer conversion patterns using data analytics and visualization techniques. The dashboard provides insights into customer journeys, campaign performance, and factors influencing successful conversions.

---

## 🎯 Project Objective

- Analyze customer interactions throughout the marketing funnel.
- Identify trends and patterns affecting conversions.
- Understand customer behavior using data-driven insights.
- Create an interactive dashboard to support business decision-making.

---

## 🗂 Dataset Used

**Dataset Name:** Bank Marketing Dataset (`bank-full.csv`)

The dataset contains customer information and marketing campaign details, including:

- Customer demographics
- Job and marital information
- Education details
- Account balance
- Loan information
- Campaign details
- Previous interactions
- Subscription outcome

---

## 🛠 Tools & Technologies Used

- **Power BI** – Dashboard creation and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Creating calculated measures and KPIs
- **CSV Dataset** – Data source

---

## 📊 Dashboard Features

The interactive dashboard includes:

✅ Key Performance Indicator (KPI) Cards  
✅ Marketing Funnel Analysis  
✅ Conversion Rate Tracking  
✅ Customer Segmentation Analysis  
✅ Campaign Performance Insights  
✅ Interactive Filters and Slicers  

---

## 🔍 Key Insights

- Analyzed customer conversion patterns across different categories.
- Identified factors influencing successful marketing outcomes.
- Studied customer characteristics that impact campaign responses.
- Converted raw data into meaningful business insights through visualization.
